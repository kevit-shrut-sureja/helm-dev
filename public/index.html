Settings

Machine settings, stored in settings.json next to devscope — they apply to this machine, not to your browser. Theme, pane width and filters stay per-browser.

Keyboard shortcuts
/focus the filter box
ejump to next error
Ejump to previous error
ftoggle follow
ntoggle build/framework noise
Escdrop the trace, then close the detail pane
?this list

Single keys only — anything with Ctrl, Cmd or Alt is left to the browser, so copy and find work normally. Nothing fires while you have text selected. Clearing is deliberately button-only.

Point devscope at a workspace

devscope runs the services of an Nx monorepo and reads their logs. Give it the absolute path to one — the folder containing nx.json.
